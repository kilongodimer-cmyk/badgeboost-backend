# BadgeBoost Backend

BadgeBoost est un tableau de bord web épuré et moderne conçu pour servir de base (boilerplate / MVP) pour le lancement d'applications SaaS ou d'outils de gestion de profils/badges.

## Fonctionnalités
- **Dashboard interactif :** Interface utilisateur propre et fonctionnelle.
- **Prêt à l'emploi :** Structure légère et pensée pour être facilement personnalisée.

## Stack Technique
- **Backend / Serveur :** Python
- **Interface :** HTML5, CSS / JavaScript
